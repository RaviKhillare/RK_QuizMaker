Deployment Guide

Set up your free Google Apps Script web app in 3 simple steps.

1

Create Google Apps Script Project

Go to script.google.com -> New Project. Copy Code.gs, quiz-player.html, quiz-dashboard.html, and appsscript.json into the editor.

2

Deploy as Web App

Click Deploy -> New deployment -> Select type Web App. Set Execute as: Me and Who has access: Anyone. Copy your generated Web App URL.

3

Create Quizzes & Embed on Your Blog

Open your Web App URL to launch the QuizMaker Dashboard. Create quizzes, bulk import questions, and click Embed to copy the 1-click popup snippet for Blogger or WordPress!
